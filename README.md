**Создан хоррор-мод для tModLoader с тремя ключевыми системами:**

1. **Атмосфера Limbo** — черно-белый шейдер с виньеткой, зерном и контрастом + кастомная музыка. Работает через `ModSceneEffect` + `ModSystem`.

2. **Теневой Сталкер** — кастомный NPC, преследующий игрока ночью. Механики: замирает при взгляде, телепортируется за спину, плавное преследование с задержкой.

3. **TV-помехи** — комбинированный шейдер (Limbo + VHS-глитч): сканлайны, бегущая полоса, горизонтальные разрывы, шум. Активируется при приближении Сталкера.

**Ключевые технические решения:**
- Объединение двух шейдеров в один файл (два screen-фильтра конфликтуют)
- Имя пасса в `.fx` должно совпадать со вторым аргументом `ScreenShaderData`
- Явная загрузка текстуры через `ModContent.Request<Texture2D>(Texture)`
- Команда `/summonshadow` для быстрого тестирования
- Защита от `NullReferenceException` на каждом этапе

**Ошибки, которые пришлось преодолеть:** API-несоответствия tModLoader 1.4+, невидимость спрайта, краши при применении шейдера, зацикливание звуков, деспаун NPC.
